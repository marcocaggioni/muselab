MIDLAND.

A night-lab notebook: seven experiments in one evening with two Raspberry Pis, a Sense HAT, a micro:bit and a camera — driven by conversation, not code.

SystemPhilosophy ExperimentsWorkflow GitHub

The System

Two Raspberry Pi 4s on the home LAN, orchestrated through natural language. Hover the nodes — the animation shows live data flow.

Philosophy

Traditional tinkering: datasheets → drivers → dependency hell → debugging — hours before the first observation.

The gadget way: idea → spoken request → running demo in minutes. The experimenter thinks about the question, the observation, and what data to collect — never about SSH flags, library versions, or serial baud rates. Every experiment below went from a one-line request to live hardware in under five minutes.

Experiments

01

Message Beacon

Flash-until-read chore messenger on the Sense HAT. New message → flashing LEDs; joystick press → message scrolls once, then dark.

02

Fire Simulator

Doom-style fire algorithm on the 8×8 LED matrix — heat rises, cools, and blooms through black → red → orange → yellow.

03

Counter 1–1000

Each integer 1 to 1000 scrolled on the matrix at one-second intervals. Seventeen minutes of green numbers.

04

RGB Light Meter

Flask dashboard plotting live per-channel average intensity from the camera feed. Cover the lens — watch the traces fall.

05

Color Feedback Loop

Sense HAT cycles red/green/blue under the camera while the RGB meter watches — each channel spikes in turn. A closed loop.

06

micro:bit Hello

MicroPython flashed over USB in seconds; "hi Tommaso" scrolls on the 5×5 display.

07

Cross-Pi Sensing

Temperature/humidity read from the TEMPerX232 on Pi #1, displayed on the Sense HAT of Pi #2. Two machines, one observation.

Workflow

Every experiment followed the same loop — see WORKFLOW.md:

1. Idea — "what if the LEDs flashed when there's a message?"
2. Request — one spoken sentence, no code.
3. Build — running on hardware in minutes.
4. Observe — watch it, break it, notice things.
5. Iterate — "now make it stop flashing after reading."
